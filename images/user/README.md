# Drop-zone images — remplace par tes propres visuels (Nano Banana / compte pro)

Dépose ici tes images générées avec EXACTEMENT ces noms de fichier :
- hero-chip.png   — hero (puce Apple Silicon macro cinématique, fond noir, ~1024x576 ou 1536x864)
- corridor.png    — métaphore bande passante (couloirs, 1024x576)
- team-table.png  — métaphore mémoire unifiée (équipe autour d'une table, 1024x1024)
- die-3nm.png     — die 3 nm, blocs clairsemés bleus (768x768)
- die-2nm.png     — die 2 nm, blocs denses dorés (768x768)

Dépose les images dans /opt/data/apple-chips-guide/images/user/ OU remplace directement
les fichiers images/<nom>.png — le code les reprend automatiquement aux mêmes emplacements.

Dis simplement à Hermes où est chaque image ; il la branche au bon endroit (hero, stats,
assistant, comparatif) et déploie.
